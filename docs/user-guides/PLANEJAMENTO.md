# Planejamento de aulas

Crie plano anual/periódico/semanal ou por aula, associe currículo/habilidades, envie para revisão, agende e registre execução. Plano executado não é alterado retroativamente; crie versão/complemento. No offline, sincronize a outbox e resolva conflitos explicitamente.

Toda ação crítica exige perfil autorizado e aparece na auditoria.
